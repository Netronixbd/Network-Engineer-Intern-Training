# Networking Glossary | 100+ Terms (English + বাংলা Explanation)

| Term | Short meaning / example |
|---|---|
| Network | Connected devices for data communication |
| Node | Network device/end system |
| Endpoint | PC, mobile, server, printer, IoT device |
| Hostname | Human-readable device name |
| NIC | Network Interface Card / network adapter |
| LAN | Local Area Network, office/floor |
| WLAN | Wireless LAN, Wi-Fi-based local network |
| WAN | Wide Area Network connecting remote sites |
| MAN | Metropolitan Area Network |
| ISP | Internet Service Provider |
| IXP/NIX | Internet/neutral exchange interconnection |
| Peering | Networks exchange traffic under policy/agreement |
| Transit | Upstream provides reachability beyond direct peers |
| PNI | Private Network Interconnect |
| Core | Backbone routing/switching layer |
| POP | Point of Presence / network location |
| Access | Subscriber/user-facing connectivity layer |
| Aggregation | Combines many access links/services |
| Uplink | Link towards aggregation/core/upstream |
| Downlink | Link towards clients/access, context-sensitive |
| Ethernet | Standard wired LAN technology family |
| Frame | L2 data unit |
| Packet | L3 data unit |
| Segment | TCP data unit in common OSI framing |
| Datagram | UDP or IP data unit by context |
| Bits | Digital binary units |
| Bandwidth | Nominal capacity, usually bits/s |
| Throughput | Actual achieved data delivery rate |
| Latency | Transmission/response delay |
| RTT | Round Trip Time, request–reply duration |
| Jitter | Variation in delay |
| Packet loss | Missing packets or expected responses |
| MTU | Maximum Transmission Unit |
| MSS | TCP Maximum Segment Size |
| TTL | IPv4 packet hop limit field (Time To Live) |
| Hop Limit | IPv6 analog of TTL |
| MAC | Layer 2 Ethernet hardware address |
| ARP | IPv4 next-hop IP-to-MAC resolution |
| ND/NDP | IPv6 Neighbor Discovery |
| IPv4 | 32-bit Internet Protocol address family |
| IPv6 | 128-bit Internet Protocol address family |
| Prefix | Network bit length, e.g. /24 |
| Netmask | IPv4 subnet mask, e.g. 255.255.255.0 |
| CIDR | Classless Inter-Domain Routing |
| VLSM | Variable Length Subnet Mask allocation |
| Subnet | Logical IP network segment |
| Broadcast | Send to L2 broadcast recipients (IPv4 context) |
| Multicast | One-to-many group communication |
| Unicast | One-to-one addressing |
| Gateway | Device/next hop for another IP network |
| RIB | Routing Information Base / control-plane routes |
| FIB | Forwarding Information Base / forwarding entries |
| Static IP | Manually/fixed assigned address |
| Dynamic IP | Automatically leased/assigned address |
| DHCP | Dynamic Host Configuration Protocol |
| DORA | DHCPv4 Discover/Offer/Request/Ack |
| DNS | Domain Name System |
| Resolver | DNS component finding/caching answers |
| A Record | Domain → IPv4 |
| AAAA Record | Domain → IPv6 |
| CNAME | Canonical name alias DNS record |
| MX | Mail exchanger DNS record |
| NAT | Network Address Translation |
| PAT | Port Address Translation |
| CGNAT | Carrier-Grade NAT |
| ACL | Access Control List |
| Firewall | Traffic filtering / state policy device |
| VLAN | Virtual LAN, L2 separation |
| 802.1Q | VLAN tagging standard |
| Access Port | Commonly one untagged user VLAN |
| Trunk | Link carrying multiple VLANs |
| SVI/VLANIF | L3 interface for a VLAN |
| STP | Spanning Tree Protocol |
| RSTP | Rapid Spanning Tree Protocol |
| BPDU | Bridge Protocol Data Unit |
| LACP | Link Aggregation Control Protocol |
| LAG | Link Aggregation Group |
| PoE | Power over Ethernet |
| SSID | Wireless network name |
| RSSI | Received Signal Strength Indicator |
| SNR | Signal-to-Noise Ratio |
| SFP | Small Form-factor Pluggable transceiver |
| DOM/DDM | Digital optical monitoring/diagnostics |
| dBm | Power level relative to 1 mW (logarithmic) |
| dB | Ratio / gain / loss on logarithmic scale |
| FEC | Forward Error Correction |
| CRC/FCS | Frame error detection fields/counters |
| ODF | Optical Distribution Frame |
| GPON | Gigabit-capable Passive Optical Network |
| OLT | Optical Line Terminal |
| ONU | Optical Network Unit |
| ONT | Optical Network Terminal |
| LOS | Loss of Signal |
| PON | Passive Optical Network |
| Splitter | Passive fiber optical splitter |
| PPPoE | Point-to-Point Protocol over Ethernet |
| BNG | Broadband Network Gateway |
| BRAS | Broadband Remote Access Server, legacy/related term |
| AAA | Authentication, Authorization, Accounting |
| RADIUS | AAA protocol often used for subscribers |
| Routing | Forwarding between IP networks |
| OSPF | Open Shortest Path First |
| IS-IS | Intermediate System to Intermediate System |
| RIP | Routing Information Protocol (legacy) |
| BGP | Border Gateway Protocol |
| ASN | Autonomous System Number |
| eBGP | BGP between ASNs |
| iBGP | BGP inside same ASN |
| AS_PATH | BGP path attribute with ASN sequence |
| Local Preference | BGP intra-AS preferred exit attribute |
| MED | BGP optional multi-exit discriminator |
| RPKI | Resource Public Key Infrastructure |
| VRF | Separate L3 routing tables / virtual routing |
| MPLS | Multiprotocol Label Switching |
| SNMP | Simple Network Management Protocol |
| Syslog | Central log message transport/protocol family |
| NTP | Network Time Protocol |
| NetFlow | Network flow telemetry technology |
| IPFIX | IP Flow Information Export |
| sFlow | Sampled flow/counter telemetry |
| SLA | Service Level Agreement |
| RCA | Root Cause Analysis |
| NOC | Network Operations Center |
| SOP | Standard Operating Procedure |
| MTTR | Mean time to repair/restore (define locally) |
| Change Window | Authorized period for controlled changes |
| Rollback | Return to known good state |
