# Contributing to the Intern Training Guide

Thanks for helping improve this resource. বাংলা/English mixed technical explanations welcome।

## Rules
1. Add educational material only; no real subscriber records, credentials, company secrets or production device configs।
2. Every CLI example must identify vendor, OS release/family, lab topology, verification, and warning when disruptive।
3. Subnet/IP samples must not overlap unintentionally. Public documentation examples use TEST-NET prefixes instead of real allocated public IPs।
4. Prefer one topic per `.md`, with clear headings, expected result and troubleshooting note।
5. Cite reliable official docs/RFCs for standards and command behavior. Avoid bulk copies of copyrighted manuals।
6. Links should be relative for internal repo references.
7. Fix spelling and preserve UTF-8 Bengali text.

## Suggested PR template
- What chapter/lab changed?
- Why is the change technically correct? Source?
- Which simulator/device version tested?
- Any risk/rollback guidance?
