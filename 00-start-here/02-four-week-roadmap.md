# 4-Week Intern Roadmap | ২০ দিনের Training Plan

প্রস্তাবিত schedule: দৈনিক ২ ঘণ্টা theory + ২ ঘণ্টা lab + ৩০ মিনিট viva/review। Team-এর সময় অনুযায়ী কমবেশি করা যাবে।

| Day | Topic | Practical deliverable | Checkpoint |
|---|---|---|---|
| 01 | Network fundamentals, LAN/WAN, topology | ৩টি diagram হাতে আঁকা | ১০টি Q&A |
| 02 | OSI/TCP-IP, encapsulation | DNS+HTTP packet journey explain | Layer map |
| 03 | Ethernet, cable, interface, MAC/ARP | MAC table/ARP capture | Peer demo |
| 04 | IPv4, public/private, CIDR | /24, /26, /30 calculation | Subnet quiz |
| 05 | Windows/Linux IP, ping, DNS | Static & DHCP IP test | **Week 1 quiz** |
| 06 | Switch, VLAN, access/trunk | VLAN 10/20 lab | Ping matrix |
| 07 | Router & gateway, static route | 2-router route lab | Route output |
| 08 | DHCP, DNS, NAT/PAT | LAN clients DHCP + Internet simulation | DORA flow |
| 09 | STP, LACP, loop prevention | Controlled L2 observation | Concept check |
| 10 | IPv6 and basic OSPF concepts | IPv6 link-local/global documentation | **Week 2 lab** |
| 11 | Cisco IOS basic setup | Hostname, interface, show | CLI assessment |
| 12 | MikroTik RouterOS setup | Bridge/LAN, DHCP, NAT | Backup+verify |
| 13 | Huawei/Juniper basics | Interface, VLAN/route verification | Syntax differences |
| 14 | ISP: PPPoE, GPON, OLT, ONU | Subscriber journey drawing | Fiber terms |
| 15 | NOC: monitoring, graph, ticket | Incident template practice | **Week 3 viva** |
| 16 | Troubleshoot L1/L2 | Cable/VLAN fault isolation | Evidence report |
| 17 | Troubleshoot L3/DNS | Gateway/route/DNS scenario | Decision tree |
| 18 | Routing/BGP/IPv6/optical concepts | Peer down simulation explanation | Escalation |
| 19 | Capstone: Branch office network | Topology + IP plan + configs | Full validation |
| 20 | Final practical + viva | GitHub lab report + demo | Final score |

## Recommended grading (100 marks)
- Subnetting/IP planning: 20
- L2 switching/VLAN: 15
- Static route/DHCP/NAT: 20
- Troubleshooting methodology: 20
- Documentation, security, change control: 15
- Viva & communication: 10

**Pass guideline:** 70+ marks, তবে destructive command বা credential leak করলে mentor review mandatory।

## Mentor instructions
প্রতিদিন আগের দিনের ৫টি প্রশ্ন, নতুন topic-এর ১টি mini-lab, শেষ ১০ মিনিটে learning note। Day 05, 10, 15, 20-এ check। Sample answers মুখস্থ না করে `why/how` বলতে পারলে pass।
